# ADR 0004：确定性离线适配器是一等公民

- 状态：已采纳
- 日期：2026-10-25

## 背景

依赖云端模型的仓库通常有两个问题：没有密钥就无法运行，测试只能 mock 掉关键路径。
结果是"引用可定位""时长受控""预算不越界"这些真正的约束从未在 CI 里被验证过。

## 决策

`PROVIDER_MODE=fake`（默认）提供一整套确定性适配器：

| 适配器 | 实现 | 仍然真实的性质 |
| --- | --- | --- |
| LLM | 规则化 focus / gap / draft / verify | 输出仍经过同一套 Pydantic 模型与业务校验 |
| Embedding | 特征哈希向量（1024 维、L2 归一） | 检索真的按相似度排序，不是随机返回 |
| Search | 检索本地 `evals/fixtures/web` 语料 | 缺口补证路径真的会抓取并切片外部页面 |
| TTS | 生成 24 kHz PCM，时长 = 字数 / 4.2 | 音频是真的 WAV，经 ffmpeg 编码为真的 MP3 |
| Storage | 本地内容寻址目录 | 写入不可覆盖、范围读取真实存在 |

集成测试使用真实 PostgreSQL、真实 ffmpeg/ffprobe 与真实 HTTP 层，因此 CI 不需要任何密钥。

## 后果

- 好处：任何人 `git clone` 后能复现测试、演示与评测报告；约束的回归会立刻暴露。
- 代价：离线 LLM 不做真正的改写，讲解质量只代表"按证据逐句组织"的基线；
  这部分必须在接上云端模型后重新评估，报告里也明确写了这一点。
- 云端适配器（DashScope / Tavily / S3）通过同一 Protocol 接入，切换只改配置；
  没有密钥时它们不参与验证，这一点在 README 的"已知边界"里如实标注。
